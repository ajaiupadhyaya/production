# Quick Start Guide

Get your trading platform up and running in 5 minutes!

## Prerequisites
- Python 3.10+ installed
- Node.js 18+ installed (for frontend)

## Quick Demo

```bash
# Install minimal dependencies
pip install pydantic pydantic-settings python-dotenv loguru pandas numpy sqlalchemy

# Run demo
python3 demo.py
```

See full documentation in README.md for complete setup instructions.
